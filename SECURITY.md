# Security Policy

## Supported Versions

Only the latest release and the current `main` branch receive security fixes.

## Reporting a Vulnerability

Please do not report security issues in public issues or pull requests.

Report privately using GitHub's **Report a vulnerability** button on the
[Security tab](../../security/advisories/new) of this repository.

Please include:
- A description of the issue and its impact
- Steps to reproduce, or a proof of concept
- The affected version or commit

## What to Expect

- Acknowledgement within 7 days
- An update on the fix or a decision within 30 days
- Credit in the release notes if you want it

Thank you for helping keep this project and its users safe.
